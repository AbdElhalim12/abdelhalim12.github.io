get all hidden objects in viewport and check if they showed in render and if so disable render.

Download the zip file, go to preferences -> addons -> install from disk then choose the addon zip file.

the addon will be sitting the N-Panel -> view

you got:

**Sync Viewport to Render** which hide the objects in the render that are hidden in the viewport.

**Sync Render to Viewport** will hide the object in the viewport that are hidden in the render

**Show All Objects** will show all the hidden object in both render and viewport

**Hide Unselected** will hide the unselected object in both render and viewport
